## 3. 步骤一：前端登录页面

### 3.1 Login.vue

文件路径：`frontend_admin/src/views/login/index.vue`

```vue
<template>
  <div class="login-container">
    <el-form ref="loginForm" :model="loginForm" :rules="rules">
      <h2>BareZen OA 管理系统</h2>
      <el-form-item prop="username">
        <el-input v-model="loginForm.username" placeholder="用户名" />
      </el-form-item>
      <el-form-item prop="password">
        <el-input v-model="loginForm.password" type="password" placeholder="密码"
                  @keyup.enter="handleLogin" />
      </el-form-item>
      <el-form-item>
        <el-button type="primary" :loading="loading" @click="handleLogin"
                   style="width:100%">登 录</el-button>
      </el-form-item>
    </el-form>
  </div>
</template>

<script setup>
import { ref, reactive } from 'vue'
import { useRouter } from 'vue-router'
import { login } from '@/api/auth'

const router = useRouter()
const loading = ref(false)

const loginForm = reactive({
  username: 'admin',
  password: 'admin123'
})

const rules = {
  username: [{ required: true, message: '请输入用户名', trigger: 'blur' }],
  password: [{ required: true, message: '请输入密码', trigger: 'blur' }]
}

const handleLogin = async () => {
  loading.value = true
  try {
    // 1. 调用登录API
    const res = await login(loginForm)
    // 2. 将Token存储到localStorage
    localStorage.setItem('token', res.data)
    // 3. 跳转到首页
    router.push('/')
  } catch (error) {
    console.error('登录失败:', error)
  } finally {
    loading.value = false
  }
}
</script>
```

## 4. 步骤二：后端登录接口

### 4.1 AuthController.java

文件路径：`bz_framework_core/src/main/java/com/linan/system/controller/AuthController.java`

```java
@PassAuth               // 跳过 Token 鉴权（登录不需要 Token）
@RestController
@RequestMapping("/api/auth/v1")
public class AuthController {

    @Autowired
    private ISysUserService userService;

    /**
     * 用户登录
     * POST /api/auth/v1/login
     * Body: {"username":"admin","password":"admin123"}
     */
    @PostMapping("/login")
    public Result<String> login(@RequestBody Map<String, String> body) {
        String username = body.get("username");
        String password = body.get("password");

        // 根据用户名查询用户
        SysUser user = userService.lambdaQuery()
                .eq(SysUser::getUserName, username)
                .one();

        if (user == null) {
            return Result.error("用户名或密码错误");
        }

        // 验证密码（BCrypt加密比对）
        if (!PasswordUtil.matches(password, user.getPassword())) {
            return Result.error("用户名或密码错误");
        }

        // 检查账号状态
        if ("0".equals(user.getStatus())) {
            return Result.error("该账号已被停用，请联系管理员");
        }

        // 生成JWT Token
        String token = JwtUtil.createToken(user.getId(), user.getUserName());

        return Result.success(token);
    }
}
```

## 5. 步骤三：前端路由守卫

### 5.1 permission.js

文件路径：`frontend_admin/src/permission.js`

```javascript
import router from './router'
import { getToken } from '@/utils/auth'

// 白名单：不需要登录就可以访问的页面
const whiteList = ['/login']

router.beforeEach(async (to, from, next) => {
  const hasToken = getToken()

  if (hasToken) {
    // 已登录
    if (to.path === '/login') {
      // 已登录用户访问登录页，直接跳转到首页
      next({ path: '/' })
    } else {
      // 判断是否已获取用户信息
      const hasUserInfo = store.getters.name
      if (hasUserInfo) {
        next()
      } else {
        try {
          // 获取用户信息（角色、权限等）
          await store.dispatch('user/getInfo')
          next()
        } catch (error) {
          // Token过期，清除并跳转登录
          await store.dispatch('user/resetToken')
          next(`/login?redirect=${to.path}`)
        }
      }
    }
  } else {
    // 未登录
    if (whiteList.indexOf(to.path) !== -1) {
      next()
    } else {
      next(`/login?redirect=${to.path}`)
    }
  }
})
```

## 6. 关键知识点

### 6.1 @PassAuth 注解的作用

`@PassAuth` 注解标记的接口会跳过 Token 认证。原理是在 AuthInterceptor 中检查请求是否来自标记了 @PassAuth 的 Controller：

```java
// AuthInterceptor.preHandle() 中的判断逻辑
if (handler instanceof HandlerMethod) {
    HandlerMethod hm = (HandlerMethod) handler;
    // 如果Controller类上有 @PassAuth 注解，跳过Token验证
    if (hm.getBeanType().isAnnotationPresent(PassAuth.class)) {
        return true;
    }
}
```

### 6.2 Token 存储位置

| 存储位置 | 优点 | 缺点 |
| :--- | :--- | :--- |
| localStorage | 持久存储，关闭浏览器不丢失 | 可能被 XSS 攻击读取 |
| sessionStorage | 关闭标签页即清除 | 每次打开新标签页需重新登录 |
| Cookie | 可设置 HttpOnly 防止 JS 读取 | 有 CSRF 风险 |

本项目采用 localStorage，前端项目统一使用此方案。
