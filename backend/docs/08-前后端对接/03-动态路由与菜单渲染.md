# 03-动态路由与菜单渲染

## 1. 功能概述

动态路由是根据用户登录后的权限从后端获取菜单数据，由前端动态生成 Vue Router 路由和侧边栏菜单。不同用户登录后看到的菜单和可访问的页面不同。

**一句话总结**：管理员看到全套菜单，普通用户只看到被授权的菜单。

---

## 2. 动态路由加载流程

```text
用户登录成功
  -> 存储 Token 到 localStorage
  -> 跳转首页
  -> 路由守卫 beforeResolve 触发
    -> 调用后端接口 GET /api/system/v1/menus/routers
    -> 后端根据用户角色查询菜单列表
    -> 组装为树形结构返回
  -> 前端将树形菜单转换为 Vue Router 路由
  -> router.addRoute() 动态添加路由
  -> 页面渲染侧边栏菜单
```

## 4. 步骤二：前端动态生成路由

### 4.1 router/generateRoutes.js

文件路径：`frontend_admin/src/router/generateRoutes.js`

```javascript
import Layout from '@/layout'
import { getRouters } from '@/api/system/menu'

/**
 * 将后端返回的菜单树转换为 Vue Router 路由
 *
 * 后端返回的菜单格式：
 * { path: '/system', component: 'Layout', children: [
 *   { path: 'user', component: 'system/user/index' }
 * ]}
 *
 * 转换后的 Vue Router 路由格式：
 * { path: '/system', component: Layout, redirect: 'noRedirect',
 *   children: [
 *     { path: 'user', component: () => import('@/views/system/user/index'),
 *       meta: { title: '用户管理' } }
 *   ] }
 */
export function filterAsyncRoutes(routes) {
  const res = []

  routes.forEach(route => {
    const tmp = { ...route }

    // 根据 component 字符串动态导入组件
    if (tmp.component) {
      if (tmp.component === 'Layout') {
        tmp.component = Layout
      } else {
        tmp.component = loadView(tmp.component)
      }
    }

    // 递归处理子菜单
    if (tmp.children && tmp.children.length > 0) {
      tmp.children = filterAsyncRoutes(tmp.children)
    }

    res.push(tmp)
  })

  return res
}

// 动态导入组件（基于 Vite 的 import.meta.glob）
const modules = import.meta.glob('@/views/**/*.vue')
function loadView(view) {
  for (const path in modules) {
    if (path.includes(view)) {
      return modules[path]
    }
  }
}
```

## 5. 步骤三：侧边栏菜单渲染

### 5.1 Sidebar/index.vue

文件路径：`frontend_admin/src/layout/components/Sidebar/index.vue`

```vue
<template>
  <el-menu
    :default-active="activeMenu"
    :collapse="isCollapse"
    background-color="#304156"
    text-color="#bfcbd9"
    active-text-color="#409EFF"
    mode="vertical"
  >
    <sidebar-item
      v-for="route in routes"
      :key="route.path"
      :item="route"
      :base-path="route.path"
    />
  </el-menu>
</template>

<script setup>
import { computed } from 'vue'
import { useRoute } from 'vue-router'
import { useStore } from 'vuex'
import SidebarItem from './SidebarItem'

const route = useRoute()
const store = useStore()

// 从 Vuex Store 中获取用户的路由菜单
const routes = computed(() => store.getters.routes)
const activeMenu = computed(() => route.path)
</script>
```

### 5.2 SidebarItem.vue（递归组件）

```vue
<template>
  <div v-if="!item.hidden">
    <!-- 没有子菜单：直接渲染为菜单项 -->
    <template v-if="!hasChildren">
      <el-menu-item :index="resolvePath(item.path)">
        <el-icon v-if="item.meta?.icon"><component :is="item.meta.icon" /></el-icon>
        <span>{{ item.meta?.title }}</span>
      </el-menu-item>
    </template>

    <!-- 有子菜单：渲染为可展开的子菜单 -->
    <el-sub-menu v-else :index="resolvePath(item.path)">
      <template #title>
        <el-icon v-if="item.meta?.icon"><component :is="item.meta.icon" /></el-icon>
        <span>{{ item.meta?.title }}</span>
      </template>
      <sidebar-item
        v-for="child in item.children"
        :key="child.path"
        :item="child"
        :base-path="resolvePath(child.path)"
      />
    </el-sub-menu>
  </div>
</template>

<script setup>
import { computed } from 'vue'

const props = defineProps({
  item: { type: Object, required: true },
  basePath: { type: String, default: '' }
})

const hasChildren = computed(() =>
  props.item.children && props.item.children.length > 0
)

function resolvePath(routePath) {
  return props.basePath + '/' + routePath
}
</script>
```

**递归组件说明**：
`SidebarItem` 可以渲染自身（`<sidebar-item>` 中嵌套 `<sidebar-item>`），实现无限层级的菜单支持。

## 6. 三种菜单类型在前端的对应关系

| 后端 menu_type | 创建 Vue 路由 | 在侧边栏显示 | 前端操作 |
| :--- | :---: | :---: | :--- |
| M（目录） | 是（组件=Layout） | 可展开的父菜单 | |
| C（菜单） | 是 | 可点击的叶子菜单 | 点击跳转页面 |
| F（按钮） | 否 | 不显示 | 通过 v-permission 控制按钮显隐 |

**为什么 F（按钮）不创建路由？**
按钮级权限用于控制页面内的操作权限（如"新增"、"删除"按钮），不需要映射到 Vue Router。

---

## 7. 按钮级权限控制

### 7.1 v-permission 指令

```javascript
// frontend_admin/src/directive/permission.js

export default {
  mounted(el, binding) {
    const { value } = binding  // 需要拥有的权限标识
    const permissions = store.getters.permissions  // 当前用户拥有的权限列表

    if (value && value instanceof Array && value.length > 0) {
      const hasPermission = permissions.some(p => value.includes(p))
      if (!hasPermission) {
        el.parentNode && el.parentNode.removeChild(el)  // 移除无权限的按钮
      }
    }
  }
}
```

使用方式：

```vue
<!-- 只有拥有 system:user:add 权限的用户才能看到此按钮 -->
<el-button v-permission="['system:user:add']" type="primary">新增</el-button>
```
