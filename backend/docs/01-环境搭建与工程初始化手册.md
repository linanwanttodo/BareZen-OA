# 01-环境搭建与工程初始化手册

欢迎加入 **BareZen_Base (BareZen_Base)** 项目的开发！本手册将指导你完成从环境配置到项目启动的全过程。

## 1. 前置要求
在开始之前，请确保你的本地环境已安装以下工具：
- **JDK 21+**: 本项目强制使用 Java 21，以利用虚拟线程等现代特性。
- **Docker & Docker Compose**: 用于一键拉起 MySQL 和 Redis。
- **IntelliJ IDEA**: 推荐使用最新版本，并安装 Kotlin 插件。
- **Make** (可选): 用于运行便捷的启动脚本（Arch Linux 用户通常自带）。

## 2. 数据库环境编排
我们使用 `docker-compose.yml` 来管理基础中间件。在项目根目录执行：

```bash
make env-up
# 或者直接使用 docker 命令
docker-compose up -d
```

这将启动：
- **MySQL 8.0**: 端口 `3306`，默认密码 `123456`，自动创建 `barezen_base` 库。
- **Redis 7.0**: 端口 `6379`。

## 3. Gradle 多模块配置
本项目采用 Gradle Kotlin DSL (`.kts`) 构建，项目名称为 `BareZen_Base`，包名统一使用 `com.linan`。

### 核心配置说明
- **根目录 `build.gradle.kts`**:
  - 引入了 `io.spring.dependency-management` 插件，**这是子模块能够省略依赖版本号的关键**。
  - 统一定义了 Spring Boot 3.2.4、Java 21 兼容性以及 Lombok 依赖。
- **子模块**:
  - `bz_framework_core`: 核心底座，提供统一返回体和异常处理。
  - `bz_web_app`: 业务启动入口。

## 4. 启动后端服务
配置好环境后，你可以通过以下命令启动主应用：

```bash
make dev-api
# 或者
./gradlew :bz_web_app:bootRun
```

## 5. 常见问题
- **Q: 遇到 `prepareKotlinBuildScriptModel` 错误？**
  - A: 请在 IDEA 中刷新 Gradle 项目，或重启 IDEA。确保已安装 Kotlin 插件。
- **Q: 数据库连接失败？**
  - A: 检查 Docker 容器是否正常运行 (`docker ps`)，并确认 `application.yml` 中的密码配置。
