# 01-环境搭建与工程初始化

## 1. 概述

本章将指导你完成 BareZen_Base 后端的开发环境搭建和项目初始化工作。完成本章后，你将具备一个可以正常编译和启动的 Gradle 多模块 Java 项目骨架。

本章包含以下内容：
- JDK 21 的环境配置与验证
- IntelliJ IDEA 的安装与 Gradle 插件配置
- 项目拉取与导入
- 首次编译验证

---

## 2. 前置要求

在开始之前，请确保你的本地环境满足以下条件：

| 工具 | 最低版本要求 | 验证命令 | 说明 |
| :--- | :--- | :--- | :--- |
| JDK | 21+ | `java -version` | 本项目强制使用 Java 21，以利用虚拟线程等现代特性 |
| Gradle | 8.5+ | `./gradlew --version` | 项目自带 Gradle Wrapper，无需手动安装 |
| Git | 2.30+ | `git --version` | 用于代码版本管理 |
| IDEA | 2023.3+ | 关于面板查看 | 推荐 IntelliJ IDEA Ultimate，需安装 Kotlin 插件 |
| Docker | 24+ | `docker --version` | 用于启动 MySQL 和 Redis |
| Make | 4.0+ | `make --version` | 可选，用于执行便捷管理命令 |

## 3. JDK 21 安装与配置

### 3.1 Arch Linux 安装

如果你使用的是 Arch Linux（本项目推荐的开发环境），执行以下命令：

```bash
# 安装 JDK 21
sudo pacman -S jdk21-openjdk

# 验证安装
java -version
# 预期输出：openjdk version "21.0.x" ...

# 设置 JAVA_HOME 环境变量（编辑 ~/.zshrc 或 ~/.bashrc）
echo 'export JAVA_HOME=/usr/lib/jvm/java-21-openjdk' >> ~/.zshrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.zshrc

# 使配置生效
source ~/.zshrc
```

### 3.2 Ubuntu / Debian 安装

```bash
sudo apt update
sudo apt install openjdk-21-jdk

java -version
# 预期输出：openjdk version "21.0.x"
```

### 3.3 macOS 安装

```bash
# 使用 Homebrew
brew install openjdk@21

# 设置 JAVA_HOME
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 21)' >> ~/.zshrc
source ~/.zshrc
```

### 3.4 Windows 安装

1. 前往 [Adoptium](https://adoptium.net/) 或 [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) 下载 JDK 21 安装包。
2. 运行安装程序，选择"添加至 PATH"。
3. 设置环境变量 `JAVA_HOME` 指向安装目录（如 `C:\Program Files\Java\jdk-21`）。
4. 打开命令提示符或 PowerShell，执行 `java -version` 验证。

### 3.5 多 JDK 版本管理

如果你的系统安装了多个 JDK 版本，可以使用以下方式切换：

```bash
# Arch Linux 使用 archlinux-java 工具
archlinux-java status          # 查看已安装的 JDK 列表
sudo archlinux-java set java-21-openjdk   # 设置为 JDK 21
```

## 4. IntelliJ IDEA 配置

### 4.1 确保 Kotlin 插件已启用

本项目的 Gradle 构建脚本使用 Kotlin DSL（`.kts` 文件），IntelliJ IDEA 需要 Kotlin 插件支持。

1. 打开 IDEA，进入 `File -> Settings -> Plugins`（macOS: `Preferences -> Plugins`）
2. 搜索 "Kotlin"
3. 确保 "Kotlin" 插件已安装并启用
4. 如果提示需要重启，重启 IDEA

### 4.2 配置项目 JDK

1. 打开项目后，进入 `File -> Project Structure -> Project`
2. "SDK" 选择 JDK 21
3. "Language level" 选择 "21 - Record patterns, pattern matching for switch"

### 4.3 配置 Gradle JVM

1. 进入 `File -> Settings -> Build, Execution, Deployment -> Build Tools -> Gradle`
2. "Gradle JVM" 选择 JDK 21
3. "Build and run using" 选择 "Gradle"
4. "Run tests using" 选择 "Gradle"

这样配置后，IDEA 的 Gradle 面板将正确识别项目的模块结构。

## 5. 项目拉取与导入

### 5.1 拉取代码

```bash
# 克隆项目（根据实际仓库地址调整）
git clone <repository-url> BareZen_Base
cd BareZen_Base
```

### 5.2 项目目录结构预览

拉取后你会看到如下目录结构：

```text
BareZen_Base/
├── BareZen_Base-Full-Design-Doc.md      # 总体设计文档
├── BareZen_Base-Developer-Guide.md      # 开发落地手册
├── BareZen_Base-vs-RuoYi.md             # 对标若依介绍
├── backend/                          # 后端项目根目录
│   ├── build.gradle.kts             # 根构建脚本（全局依赖管理）
│   ├── settings.gradle.kts          # 模块包含配置
│   ├── docker-compose.yml           # Docker 中间件编排
│   ├── Makefile                     # 便捷管理命令
│   ├── gradlew                      # Gradle Wrapper（Linux/macOS）
│   ├── gradlew.bat                  # Gradle Wrapper（Windows）
│   ├── docs/                        # 开发手册目录
│   ├── bz_framework_core/           # 核心底座模块
│   └── bz_web_app/                  # Web 应用启动模块
├── frontend_admin/                   # 管理端前端（Vue3）
└── frontend_user/                    # 用户端前端（Vue3）
```

### 5.3 使用 IDEA 导入项目

1. 打开 IntelliJ IDEA
2. 选择 `File -> Open`（或 `Open` 按钮）
3. 定位到 `BareZen_Base/backend` 目录
4. 选择 `build.gradle.kts` 文件，点击 "Open"
5. 在弹出对话框中选择 "Open as Project"
6. IDEA 将自动下载 Gradle 依赖并索引项目（首次可能需要几分钟）

项目导入成功后可看到：
- Gradle 面板中出现 `BareZen_Base` 根项目和 `bz_framework_core`、`bz_web_app` 两个子模块
- IDE 底部的构建状态显示 "BUILD SUCCESSFUL"

## 6. 首次编译验证

### 6.1 通过命令行编译

在 `backend` 目录下执行：

```bash
# 赋予 gradlew 执行权限（仅需执行一次）
chmod +x gradlew

# 清理并编译所有模块
./gradlew clean build
```

预期输出：

```
BUILD SUCCESSFUL in 5s
4 actionable tasks: 4 executed
```

### 6.2 通过 IDEA 编译

1. 打开右侧 `Gradle` 面板
2. 展开 `BareZen_Base -> Tasks -> build`
3. 双击 `build` 任务

### 6.3 编译失败排查

如果出现编译错误，请逐一检查：

| 错误症状 | 可能原因 | 解决方案 |
| :--- | :--- | :--- |
| `Could not resolve ...` | 网络问题或仓库不可达 | 检查网络，settings.gradle.kts 已配置阿里云镜像 |
| `Unsupported class file major version 65` | JDK 版本低于 21 | 确认 JAVA_HOME 指向 JDK 21 |
| `Cannot find symbol: Xxx` | IDE 缓存问题 | 执行 `File -> Invalidate Caches and Restart` |
| `prepareKotlinBuildScriptModel` 错误 | Kotlin 插件未安装 | 安装 IDEA Kotlin 插件并重启 |
| `Lombok requires annotation processing` | 注解处理器未启用 | Settings -> Build -> Compiler -> Annotation Processors，勾选 "Enable annotation processing" |

### 6.4 启用 Lombok 注解处理（重要）

Lombok 依赖注解处理器生成代码（如 `getter/setter`），必须在 IDEA 中启用：

1. `File -> Settings -> Build, Execution, Deployment -> Compiler -> Annotation Processors`
2. 勾选 "Enable annotation processing"
3. 点击 Apply -> OK

如果不启用，IDEA 会提示 "Cannot resolve method 'getXxx()'" 等错误，但 Gradle 命令行编译不受影响。

## 7. 项目构建脚本解读

### 7.1 根构建脚本（build.gradle.kts）

根脚本的作用是统一管理所有子模块的公共配置：

```kotlin
// 文件路径：backend/build.gradle.kts

plugins {
    id("java")
    // spring-boot 插件声明为 apply false，表示仅引入插件但不应用到根项目
    // 具体子模块需要时才单独应用
    id("org.springframework.boot") version "3.2.4" apply false
    // Spring 依赖管理插件，这是子模块能省略版本号的关键
    id("io.spring.dependency-management") version "1.1.7" apply false
    kotlin("jvm") version "1.9.0" apply false
}

// 全局组织名和版本号
group = "com.linan"
version = "1.0-SNAPSHOT"

// 所有项目（包括根项目和子项目）的仓库配置
allprojects {
    repositories {
        mavenCentral()
        maven { url = uri("https://maven.aliyun.com/repository/public") }
    }
}

// 所有子模块的公共配置
subprojects {
    apply(plugin = "java")
    apply(plugin = "io.spring.dependency-management")

    // 引入 Spring Boot BOM 统一管理版本
    // BOM（Bill of Materials）定义了一组兼容的依赖版本
    // 引入后子模块可直接使用 spring-boot-starter-web 等而不指定版本号
    dependencies {
        implementation(platform("org.springframework.boot:spring-boot-dependencies:3.2.4"))
    }

    // 强制使用 Java 21
    java {
        sourceCompatibility = JavaVersion.VERSION_21
        targetCompatibility = JavaVersion.VERSION_21
    }

    // 所有子模块默认引入 Lombok
    dependencies {
        compileOnly("org.projectlombok:lombok")
        annotationProcessor("org.projectlombok:lombok")
        // 测试依赖
        testImplementation(platform("org.junit:junit-bom:6.0.0"))
        testImplementation("org.junit.jupiter:junit-jupiter")
        testRuntimeOnly("org.junit.platform:junit-platform-launcher")
    }

    tasks.test {
        useJUnitPlatform()
    }
}
```

关键点说明：
- `apply false`：声明插件但不应用，子模块按需使用
- `allprojects`：作用于所有项目（包括根项目）
- `subprojects`：仅作用于子模块
- `platform("...spring-boot-dependencies")`：引入 BOM，统一管理 Spring 生态依赖版本
- `compileOnly` vs `annotationProcessor`：Lombok 在编译时生成代码，运行时不需要

### 7.2 模块包含配置（settings.gradle.kts）

```kotlin
// 文件路径：backend/settings.gradle.kts

rootProject.name = "BareZen_Base"

// 包含子模块，每个子模块对应一个目录
include("bz_framework_core")  // 核心底座模块
include("bz_web_app")         // Web 应用启动模块

// 插件管理仓库配置（用于下载 Gradle 插件本身）
pluginManagement {
    repositories {
        maven { url = uri("https://maven.aliyun.com/repository/gradle-plugin") }
        maven { url = uri("https://maven.aliyun.com/repository/public") }
    }
}

// 依赖解析管理仓库配置（用于下载项目依赖）
dependencyResolutionManagement {
    repositories {
        maven { url = uri("https://maven.aliyun.com/repository/public") }
        maven { url = uri("https://maven.aliyun.com/repository/spring") }
        maven { url = uri("https://maven.aliyun.com/repository/google") }
    }
}
```

关键点说明：
- `include("模块名")`：声明项目包含的子模块，名称为目录名
- `pluginManagement`：Gradle 插件自身的下载仓库
- `dependencyResolutionManagement`：项目依赖的下载仓库
- 阿里云镜像用于加速国内下载
