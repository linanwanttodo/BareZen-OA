# 02-核心底座开发手册 (bz_framework_core)

`bz_framework_core` 是 BareZen_OA 的微内核，它不包含任何具体的业务逻辑，而是为所有上层模块提供通用的技术支撑。包名统一为 `com.linan.core`。

## 1. 统一 API 规范
为了保证前后端交互的一致性，我们定义了标准的返回体 `Result<T>`。

### 核心类结构
- **`ResultCodeEnum`**: 定义全局状态码（如 200 成功, 401 未授权）。
- **`Result<T>`**: 包含 `code`, `msg`, `data` 三个字段。

### 使用示例
```java
@GetMapping("/hello")
public Result<String> hello() {
    return Result.success("Hello BareZen_OA");
}
```

## 2. 全局异常防线
通过 `@RestControllerAdvice` 实现全局异常捕获，确保后端永远不会直接向前端抛出 Tomcat 默认的错误页面。

### 处理逻辑
1. **业务异常 (`RuntimeException`)**: 记录警告日志，返回自定义错误信息。
2. **系统异常 (`Exception`)**: 记录错误堆栈，返回统一的“服务器开小差”提示。

## 3. 极简 JWT 鉴权引擎
我们不使用臃肿的 Spring Security，而是采用轻量级的拦截器方案。

### 核心组件
- **`JwtUtil`**: 负责 Token 的生成与解析（基于 `jjwt 0.12+`）。
- **`PassAuth`**: 自定义注解，用于标记不需要登录即可访问的接口（如登录页、首页）。
- **`AuthInterceptor`** (待实现): 拦截请求，校验 Header 中的 `Authorization` 字段。

### 代码示例
```java
// 生成 Token
String token = JwtUtil.createToken(1L, "admin");

// 在 Controller 中放行接口
@PassAuth
@GetMapping("/public/info")
public Result<String> publicInfo() {
    return Result.success("公开信息");
}
```

## 4. 开发建议
- **保持纯净**: 严禁在 `core` 模块中引入业务相关的表或 Service。
- **日志规范**: 所有异常必须通过 `GlobalExceptionHandler` 统一输出日志。
