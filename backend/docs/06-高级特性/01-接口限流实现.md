# 01-接口限流实现

## 1. 功能概述

接口限流（Rate Limiting）是保护系统不被恶意请求或突发流量击垮的重要手段。当某个接口的请求频率超过设定阈值时，限流器会拒绝后续请求并返回错误提示。

**典型场景**：

| 场景 | 限制规则 | 原因 |
| :--- | :--- | :--- |
| 登录接口 | 每分钟 5 次 | 防止暴力破解密码 |
| 短信验证码 | 每分钟 1 次 | 防止短信被刷，节约成本 |
| 普通 API | 每秒 100 次 | 防止突发流量击垮数据库 |
| 文件上传 | 每分钟 10 次 | 防止磁盘被打满 |

## 2. 设计原理

### 2.1 限流算法选择

| 算法 | 原理 | 优缺点 |
| :--- | :--- | :--- |
| 计数器 | 固定窗口内计数 | 简单但有临界突变 |
| 滑动窗口 | 细化时间窗口 | 比计数器平滑 |
| 令牌桶 | 按速率发放令牌 | **允许一定突发**，更灵活 |

本项目采用 **Redis + Lua 脚本** 实现令牌桶/计数器算法。Redis 保证多实例共享限流状态，Lua 脚本保证原子性。

### 2.2 Redis + Lua 实现

```lua
-- rate_limit.lua
local key = KEYS[1]
local limit = tonumber(ARGV[1])  -- 阈值
local window = tonumber(ARGV[2]) -- 窗口（秒）

local current = redis.call('INCR', key)
if current == 1 then
    redis.call('EXPIRE', key, window)
end

if current > limit then
    return 0  -- 超过限流
else
    return 1  -- 通过
end
```

**优势**：Redis INCR 是原子操作，Lua 脚本将"检查+计数+设置过期"打包为原子执行，避免并发竞态。

## 4. @RateLimit 注解

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface RateLimit {
    /** 限流 key，默认空（自动生成） */
    String key() default "";

    /** 时间窗口内最大请求次数，默认 5 */
    int limit() default 5;

    /** 时间窗口大小（秒），默认 60 */
    int window() default 60;
}
```

## 5. RateLimitAspect 核心实现

```java
@Aspect
@Component
public class RateLimitAspect {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    private static final String RATE_LIMIT_PREFIX = "rate_limit:";

    // Lua 脚本：原子性限流检查
    private static final String LUA_SCRIPT =
            "local key = KEYS[1] " +
            "local limit = tonumber(ARGV[1]) " +
            "local window = tonumber(ARGV[2]) " +
            "local current = redis.call('INCR', key) " +
            "if current == 1 then redis.call('EXPIRE', key, window) end " +
            "if current > limit then return 0 else return 1 end";

    @Around("@annotation(RateLimit)")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        RateLimit rateLimit = getAnnotation(joinPoint);
        String key = buildKey(rateLimit, joinPoint);

        DefaultRedisScript<Long> script = new DefaultRedisScript<>(LUA_SCRIPT, Long.class);
        Long result = redisTemplate.execute(script,
            Collections.singletonList(RATE_LIMIT_PREFIX + key),
            String.valueOf(rateLimit.limit()),
            String.valueOf(rateLimit.window())
        );

        if (result == null || result == 0) {
            return Result.error("请求过于频繁，请稍后再试");
        }
        return joinPoint.proceed();
    }

    // key 格式：rate_limit:{ip}:{method}:{path}
    private String buildKey(RateLimit rateLimit, ProceedingJoinPoint joinPoint) {
        if (!rateLimit.key().isEmpty()) {
            return rateLimit.key();
        }
        HttpServletRequest request = getRequest();
        return request.getRemoteAddr() + ":" + request.getMethod() + ":" + request.getRequestURI();
    }
}
```

## 6. 使用示例

### 限制登录接口

```java
@PassAuth
@RestController
@RequestMapping("/api/auth/v1")
public class AuthController {

    @RateLimit(key = "login", limit = 5, window = 60)
    @PostMapping("/login")
    public Result<Map<String, Object>> login(@RequestBody Map<String, String> body) {
        // 每IP每分钟最多5次登录尝试
    }
}
```

### 限制短信发送

```java
@RateLimit(key = "sms", limit = 1, window = 60)
@PostMapping("/sms/send")
public Result<Void> sendSms(String phone) {
    // 每分钟最多发1条短信
}
```
