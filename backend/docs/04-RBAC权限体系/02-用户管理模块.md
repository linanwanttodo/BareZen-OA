# 02-用户管理模块

## 1. 功能概述

用户管理模块是实现系统用户增删改查的基础模块，包含以下几层：

- **Entity**：实体类 SysUser，映射 sys_user 数据库表
- **Mapper**：数据访问层，继承 BaseMapper 获得通用 CRUD 方法
- **IService + ServiceImpl**：业务逻辑层，继承 IService 获得通用 Service 方法
- **Controller**：控制层，继承 BaseController 自动获得通用 CRUD 接口

**为什么需要 Mapper、Service、Controller 三层？**

| 层次 | 职责 | 直接操作 |
| :--- | :--- | :--- |
| Mapper | SQL 映射，直连数据库 | MyBatis-Plus BaseMapper 自动生成 SQL |
| Service | 业务逻辑 + 事务管理 | 调用 Mapper，可添加业务校验 |
| Controller | HTTP 请求/响应处理 | 调用 Service，参数校验，返回 Result |

## 3. 代码实现

### 3.1 SysUser.java — 用户实体类

文件路径：`bz_framework_core/src/main/java/com/linan/system/entity/SysUser.java`

```java
package com.linan.system.entity;

import com.baomidou.mybatisplus.annotation.TableName;
import com.linan.core.common.entity.BaseEntity;
import com.fasterxml.jackson.annotation.JsonIgnore;
import lombok.Data;
import lombok.EqualsAndHashCode;

/**
 * 系统用户实体类
 *
 * 继承 BaseEntity，自动获得 id、createTime、updateTime、createBy、updateBy、delFlag 字段。
 * @TableName 指定对应的数据库表名（MyBatis-Plus 通过此注解实现表映射）。
 */
@Data
@EqualsAndHashCode(callSuper = true)    // 标记：生成 equals/hashCode 时包含父类字段
@TableName("sys_user")                   // 映射 sys_user 表

public class SysUser extends BaseEntity {

    /** 登录用户名（唯一索引，不能重复） */
    private String userName;

    /** 用户昵称（用于前端显示） */
    private String nickName;

    /**
     * 登录密码
     * 使用 BCrypt 算法加密存储，数据库中保存的是加密后的哈希串。
     * @JsonIgnore 序列化为 JSON 时忽略此字段，防止密码泄露给前端。
     */
    @JsonIgnore
    private String password;

    /** 邮箱地址 */
    private String email;

    /** 手机号 */
    private String phone;

    /** 性别：0=未知 1=男 2=女 */
    private String sex;

    /** 头像路径（文件上传后的存储路径） */
    private String avatar;

    /** 账号状态：0=停用 1=正常 */
    private String status;

    /** 最后登录 IP */
    private String loginIp;

    /** 最后登录时间 */
    private String loginDate;

    /** 备注信息 */
    private String remark;
}
```

**逐行讲解**：

- `@EqualsAndHashCode(callSuper = true)`：Lombok 自动生成 `equals()` 和 `hashCode()` 方法。`callSuper = true` 表示在计算 hashCode 时也包含父类（BaseEntity）的字段。如果不设置，即使父类 id 相同，子类也会被认为是不同对象。
- `@TableName("sys_user")`：MyBatis-Plus 注解，将实体类映射到 `sys_user` 表。如果不指定，MyBatis-Plus 会使用类名驼峰转下划线作为表名（`SYS_USER`），一般也能识别，但显式指定更安全。
- `@JsonIgnore`：Jackson 注解，在序列化 JSON 时跳过此字段。如果不加，前端调用接口会看到密码的加密串，虽然无法反向解密，但不应暴露任何密码相关信息。

### 3.5 SysUserController.java — 用户 Controller

文件路径：`bz_framework_core/src/main/java/com/linan/system/controller/SysUserController.java`

```java
package com.linan.system.controller;

import com.linan.core.common.controller.BaseController;
import com.linan.system.entity.SysUser;
import com.linan.system.service.ISysUserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

/**
 * 系统用户 Controller
 *
 * 继承 BaseController<SysUser, ISysUserService>，自动获得以下接口：
 * - GET  /api/system/v1/users/list         分页查询
 * - GET  /api/system/v1/users/{id}         根据ID查询
 * - POST /api/system/v1/users              新增
 * - PUT  /api/system/v1/users              更新
 * - DELETE /api/system/v1/users/{id}        删除
 *
 * 只包含通用的 CRUD 接口，特殊业务接口可在此类中自行添加。
 */
@RestController
@RequestMapping("/api/system/v1/users")
public class SysUserController extends BaseController<SysUser, ISysUserService> {

    @Autowired
    private ISysUserService sysUserService;

    @Override
    protected ISysUserService getService() {
        return sysUserService;
    }
}
```
