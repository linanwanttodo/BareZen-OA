# 01-数据字典管理

## 1. 功能概述

数据字典（Data Dictionary）用于管理系统中的静态配置数据，例如：性别、状态、业务类型等。通过字典管理，可以避免在代码中硬编码常量，提高系统的可维护性。

**核心特性：**
*   **Redis 缓存加速**：字典数据是典型的“读多写少”场景，系统会自动将查询过的字典数据存入 Redis，大幅提升响应速度。
*   **动态刷新**：当管理员在后台修改字典配置后，系统会自动清除对应的 Redis 缓存，确保前端获取到最新数据。

---

## 2. 设计原理

### 2.1 缓存策略
*   **Key 命名规范**：`sys_dict:{dictType}`（例如：`sys_dict:sys_user_sex`）。
*   **过期时间**：默认设置为 1 小时。
*   **加载机制**：采用“懒加载”模式。第一次查询时从数据库读取并写入缓存，后续请求直接从 Redis 获取。

### 2.2 表结构说明
*   `sys_dict_type`：字典类型表（如：用户性别）。
*   `sys_dict_data`：字典数据表（如：男、女）。

## 4. 核心代码实现

### 4.1 字典缓存逻辑 (SysDictDataServiceImpl)

```java
@Override
public List<SysDictData> selectDictDataByType(String dictType) {
    // 1. 尝试从 Redis 获取
    String cacheKey = DICT_CACHE_PREFIX + dictType;
    List<SysDictData> cachedData = (List<SysDictData>) redisTemplate.opsForValue().get(cacheKey);

    if (cachedData != null && !cachedData.isEmpty()) {
        return cachedData;
    }

    // 2. 数据库查询
    LambdaQueryWrapper<SysDictData> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(SysDictData::getDictType, dictType)
           .eq(SysDictData::getStatus, "1")
           .orderByAsc(SysDictData::getDictSort);

    List<SysDictData> dbData = dictDataMapper.selectList(wrapper);

    // 3. 写入缓存
    if (dbData != null && !dbData.isEmpty()) {
        redisTemplate.opsForValue().set(cacheKey, dbData, 1, TimeUnit.HOURS);
    }
    return dbData;
}
```
