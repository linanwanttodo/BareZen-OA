# 05-在线用户监控

## 1. 功能概述

在线用户监控用于查看当前登录系统的所有在线用户信息，包括用户名、登录IP、登录时间等。管理员可以通过此功能强制下线某个用户。

**实现原理**：
- 用户登录成功后，将用户信息存入 Redis（key = `online_user:{token}`，value = 用户信息 JSON）
- 查询在线用户时，遍历 Redis 中所有有效的 Token
- 强制下线时，删除 Redis 中对应的 Token 记录

**为什么用 Redis 而不是数据库？**

| 方案 | 优点 | 缺点 |
| :--- | :--- | :--- |
| Redis | Token 自动过期，内存速度快，无需额外字段 | 依赖 Redis，重启可能丢失（但 Token 本身也不持久） |
| 数据库加 is_online 字段 | 不依赖外部组件 | 用户异常退出时 is_online 不会更新，需要心跳维护 |

选择 Redis 是因为 Token 本身就存在 Redis 中用于鉴权，在同一处管理在线用户是自然的选择。

## 3. 核心代码实现

### 3.1 OnlineUser.java

```java
@Data
public class OnlineUser implements Serializable {
    private String token;          // Token 值
    private Long userId;           // 用户ID
    private String userName;       // 用户名
    private String nickName;       // 昵称
    private String loginIp;        // 登录 IP
    private String loginLocation;  // 登录地点（IP 解析）
    private String browser;        // 浏览器类型
    private String os;             // 操作系统
    private LocalDateTime loginTime; // 登录时间
}
```

### 3.2 OnlineUserServiceImpl — 登录记录

用户登录成功后，在 AuthController 中调用：

```java
// AuthController.login() 方法中
onlineUserService.recordLogin(user.getId(), user.getUserName(),
    user.getNickName(), token, loginIp);
```

实现：

```java
@Override
public void recordLogin(Long userId, String userName, String nickName,
                       String token, String loginIp) {
    String key = "online_user:" + token;

    OnlineUser onlineUser = new OnlineUser();
    onlineUser.setToken(token);
    onlineUser.setUserId(userId);
    onlineUser.setUserName(userName);
    onlineUser.setNickName(nickName);
    onlineUser.setLoginIp(loginIp);
    onlineUser.setLoginTime(LocalDateTime.now());

    // 存储到 Redis，TTL 与 Token 过期时间一致（24小时）
    redisTemplate.opsForValue().set(key, onlineUser, 24, TimeUnit.HOURS);
}
```

### 3.3 在线用户列表查询

```java
@Override
public List<OnlineUser> listOnlineUsers() {
    List<OnlineUser> users = new ArrayList<>();

    // 扫描所有 online_user:* 的 key
    Set<String> keys = redisTemplate.keys("online_user:*");

    for (String key : keys) {
        OnlineUser user = (OnlineUser) redisTemplate.opsForValue().get(key);
        if (user != null) {
            users.add(user);
        }
    }

    // 按登录时间倒序
    users.sort((a, b) -> b.getLoginTime().compareTo(a.getLoginTime()));
    return users;
}
```

### 3.4 强制下线

```java
@Override
public void forceLogout(String token) {
    String key = "online_user:" + token;
    redisTemplate.delete(key);
}
```

## 5. AuthInterceptor 中的黑名单检查

强制下线只删除了 Redis 中的 Token。但被下线的用户可能已将 Token 缓存到前端 localStorage 中，如果只删除 Redis key，用户在短时间内仍可用旧 Token 发送请求（因为 JWT 是无状态的，只要签名正确就会被解析）。

当前实现通过删除 `online_user:{token}` 记录即可让用户从在线列表消失。用户再次请求时，JWT 解析会成功，但不会影响在线列表。
