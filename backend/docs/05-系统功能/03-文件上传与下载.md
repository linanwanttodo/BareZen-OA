# 03-文件上传与下载实现

本模块实现了基于本地存储的文件上传与下载功能，并自动记录文件元数据到 `sys_file` 表。

## 3.1 核心逻辑说明

1. **分目录存储**：系统会根据当前日期（如 `2026/05/06`）自动创建子目录，避免单目录下文件过多。
2. **UUID 重命名**：为了防止文件名冲突和中文乱码问题，上传的文件会被重命名为 UUID 格式。
3. **数据库记录**：上传成功后，会在 `sys_file` 表中记录原始文件名、存储路径、文件大小等信息。

## 3.2 接口使用示例

### 文件上传
- **请求地址**：`POST /api/system/v1/files/upload`
- **请求参数**：`file` (MultipartFile)
- **认证**：需要 Token

```bash
curl -X POST "http://localhost:8080/api/system/v1/files/upload" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@/path/to/your/image.png"
```

### 文件下载
- **请求地址**：`GET /api/system/v1/files/download/{id}`
- **路径参数**：`id` - 文件记录ID
- **认证**：需要 Token

```bash
curl -O "http://localhost:8080/api/system/v1/files/download/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 文件删除
- **请求地址**：`DELETE /api/system/v1/files/{id}`
- **路径参数**：`id` - 文件记录ID
- **认证**：需要 Token + `@OperLog` 日志记录

## 3.4 核心代码实现

### SysFileServiceImpl — 文件上传

```java
@Override
public SysFile uploadFile(MultipartFile file) throws IOException {
    // 1. 生成唯一文件名（UUID + 原扩展名）
    String suffix = originalName.substring(originalName.lastIndexOf("."));
    String fileName = UUID.randomUUID().toString().replace("-", "") + suffix;

    // 2. 按日期分目录：uploads/2026/05/06/
    String datePath = LocalDate.now().format("yyyy/MM/dd");
    String dirPath = BASE_PATH + datePath;

    // 3. 保存文件到本地
    File dest = new File(dirPath + "/" + fileName);
    file.transferTo(dest);

    // 4. 记录到数据库
    SysFile sysFile = new SysFile();
    sysFile.setFileName(fileName);
    sysFile.setOriginalName(originalName);
    sysFile.setFilePath(dirPath + "/" + fileName);
    sysFile.setFileUrl("/api/system/v1/files/download/" + id);
    sysFile.setFileSize(file.getSize());
    sysFile.setFileType(suffix);
    sysFile.setStorageType("local");
    this.save(sysFile);
    return sysFile;
}
```

### SysFileServiceImpl — 文件下载

```java
@Override
public void downloadFile(Long id, HttpServletResponse response) {
    SysFile sysFile = this.getById(id);
    if (sysFile == null) throw new RuntimeException("文件不存在");

    File file = new File(sysFile.getFilePath());
    if (!file.exists()) throw new RuntimeException("文件已丢失");

    // 设置响应头，弹出下载框
    response.setContentType("application/octet-stream");
    response.setHeader("Content-Disposition",
        "attachment;filename=" + URLEncoder.encode(originalName, UTF_8));
    response.setContentLengthLong(sysFile.getFileSize());

    // 流式输出文件内容
    try (InputStream is = new FileInputStream(file);
         OutputStream os = response.getOutputStream()) {
        byte[] buffer = new byte[4096];
        while ((bytesRead = is.read(buffer)) != -1) {
            os.write(buffer, 0, bytesRead);
        }
    }
}
```
