# 04-通知公告管理

## 1. 功能概述

通知公告管理用于系统内发布通知和公告信息，如系统维护通知、版本更新公告、安全警告等。支持通知类型的区分（系统通知/公告）和状态管理（草稿/已发布/停用）。

**与操作日志的区别**：

| 特性 | 通知公告 | 操作日志 |
| :--- | :--- | :--- |
| 目的 | 主动推送消息 | 被动记录行为 |
| 受众 | 所有用户或指定用户 | 仅管理员查看 |
| 内容 | 富文本（HTML） | JSON 结构化数据 |
| 显示位置 | 首页/弹窗 | 后台管理页面 |
| 操作 | 管理员发布 | AOP 自动记录 |
| 生命周期 | 草稿→发布→下架 | 永久保存 |

**通知类型区分**：

| 类型编码 | 名称 | 显示方式 | 示例 |
| :--- | :--- | :--- | :--- |
| 1 | 系统通知 | 登录后弹窗 | "您的密码将于3天后过期" |
| 2 | 公告 | 首页公告栏 | "系统将于本周六凌晨维护" |

---

## 2. 设计原理

### 2.1 通知展示逻辑

前端需要根据通知类型做不同展示：

**通知（类型1）**：用户登录后调用接口 `GET /api/system/v1/notices/latest`，获取最新未读通知，前端弹窗显示。

**公告（类型2）**：首页调用接口 `GET /api/system/v1/notices/published`，获取所有已发布公告，在公告栏列表中显示。

### 2.2 状态管理

| 状态 | 值 | 含义 | 前端可见 |
| :--- | :---: | :--- | :---: |
| 草稿 | 0 | 仅创建者可见，编辑中 | 否 |
| 已发布 | 1 | 指定受众可见 | 是 |
| 已下架 | 2 | 不再展示 | 否 |

### 2.3 内容存储

`noticeContent` 字段存储 **HTML 富文本**，支持：
- 文字格式（粗体、斜体、颜色）
- 图片嵌入
- 超链接
- 表格

前端使用富文本编辑器（如 Tinymce、Quill）编辑，后端直接存储 HTML 字符串。

## 3. 步骤一：创建 SysNotice 实体类

### 3.1 SysNotice.java

文件路径：`bz_framework_core/src/main/java/com/linan/system/entity/SysNotice.java`

```java
package com.linan.system.entity;

import com.baomidou.mybatisplus.annotation.TableName;
import com.linan.core.common.entity.BaseEntity;
import lombok.Data;
import lombok.EqualsAndHashCode;

/**
 * 通知公告实体，对应 sys_notice 表
 *
 * 设计要点：
 * - noticeContent 使用 TEXT 类型，存储富文本 HTML
 * - noticeType 区分通知和公告，前端据此选择不同展示方式
 * - status 支持草稿/发布/下架三态管理
 */
@Data
@EqualsAndHashCode(callSuper = true)
@TableName("sys_notice")
public class SysNotice extends BaseEntity {
    /** 通知标题（如：系统维护通知） */
    private String noticeTitle;

    /** 通知内容（HTML 富文本，支持排版和图片） */
    private String noticeContent;

    /** 通知类型：1=系统通知（弹窗） 2=公告（首页展示） */
    private String noticeType;

    /** 状态：0=草稿 1=已发布 2=已下架 */
    private String status;
}
```

**字段说明**：
- `noticeType`：字符串而非数字，便于扩展（后续可加"3=紧急通知"）
- `status`：三态管理而非简单的"发布/未发布"，更符合实际业务需求

## 4. 步骤二：建表 SQL

```sql
DROP TABLE IF EXISTS sys_notice;
CREATE TABLE sys_notice (
    id             BIGINT PRIMARY KEY COMMENT '主键ID',
    notice_title   VARCHAR(128) NOT NULL COMMENT '通知标题',
    notice_content TEXT COMMENT '通知内容（HTML富文本）',
    notice_type    CHAR(1) DEFAULT '2' COMMENT '类型：1=通知 2=公告',
    status         CHAR(1) DEFAULT '0' COMMENT '状态：0=草稿 1=已发布 2=已下架',
    create_time    DATETIME NOT NULL COMMENT '创建时间',
    update_time    DATETIME NOT NULL COMMENT '更新时间',
    create_by      BIGINT DEFAULT NULL COMMENT '创建者',
    update_by      BIGINT DEFAULT NULL COMMENT '更新者',
    del_flag       TINYINT DEFAULT 0 COMMENT '逻辑删除',
    INDEX idx_type_status (notice_type, status),
    INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='通知公告表';
```

**索引设计说明**：
- `idx_type_status`：组合索引，优化"查询所有已发布公告"（`WHERE notice_type='2' AND status='1'`）的查询

### 5.1 SysNoticeMapper.java

```java
@Mapper
public interface SysNoticeMapper extends BaseMapper<SysNotice> {

    /**
     * 查询已发布的公告列表（按创建时间倒序）
     */
    @Select("SELECT * FROM sys_notice " +
            "WHERE notice_type = '2' " +
            "AND status = '1' " +
            "AND del_flag = 0 " +
            "ORDER BY create_time DESC " +
            "LIMIT #{limit}")
    List<SysNotice> selectPublishedNotices(@Param("limit") int limit);

    /**
     * 查询最新未读通知（用户登录后弹窗）
     */
    @Select("SELECT * FROM sys_notice " +
            "WHERE notice_type = '1' " +
            "AND status = '1' " +
            "AND del_flag = 0 " +
            "ORDER BY create_time DESC " +
            "LIMIT 1")
    SysNotice selectLatestNotice();
}
```

### 5.2 SysNoticeServiceImpl.java

```java
@Service
public class SysNoticeServiceImpl
        extends ServiceImpl<SysNoticeMapper, SysNotice>
        implements ISysNoticeService {

    /**
     * 发布通知（草稿→已发布）
     */
    public boolean publish(Long id) {
        SysNotice notice = getById(id);
        if (notice == null || !"0".equals(notice.getStatus())) {
            return false;  // 只能发布草稿状态的通知
        }
        notice.setStatus("1");
        return updateById(notice);
    }

    /**
     * 下架通知（已发布→已下架）
     */
    public boolean revoke(Long id) {
        SysNotice notice = getById(id);
        if (notice == null || !"1".equals(notice.getStatus())) {
            return false;  // 只能下架已发布的通知
        }
        notice.setStatus("2");
        return updateById(notice);
    }
}
```

### 5.3 SysNoticeController.java

```java
@RestController
@RequestMapping("/api/system/v1/notices")
public class SysNoticeController
        extends BaseController<SysNotice, ISysNoticeService> {

    @Autowired
    private ISysNoticeService noticeService;

    @Override
    protected ISysNoticeService getService() {
        return noticeService;
    }

    /**
     * 获取最新通知（登录后弹窗用）
     * GET /api/system/v1/notices/latest
     */
    @GetMapping("/latest")
    public Result<SysNotice> getLatest() {
        SysNotice notice = noticeService.getBaseMapper().selectLatestNotice();
        return Result.success(notice);
    }

    /**
     * 获取已发布公告列表（首页公告栏用）
     * GET /api/system/v1/notices/published
     */
    @GetMapping("/published")
    public Result<List<SysNotice>> getPublished() {
        List<SysNotice> list = noticeService.getBaseMapper()
                .selectPublishedNotices(10);  // 最多返回10条
        return Result.success(list);
    }

    /**
     * 发布通知
     * PUT /api/system/v1/notices/publish/{id}
     */
    @PutMapping("/publish/{id}")
    public Result<Void> publish(@PathVariable Long id) {
        boolean ok = noticeService.publish(id);
        return ok ? Result.success(null) : Result.error("发布失败");
    }
}
```
