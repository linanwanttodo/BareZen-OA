# 01-项目打包与部署

## 1. 功能概述

项目开发完成后，需要打包部署到生产环境服务器上运行。本章介绍 BareZen_OA 后端的打包方式、环境配置和启动方法。

---

## 2. 打包方式

### 2.1 打包为可执行 JAR

Spring Boot 可以将项目打包为一个包含所有依赖的可执行 JAR 文件（fat jar），使用内嵌的 Tomcat 服务器直接运行，无需额外安装 Tomcat。

```bash
# 在 backend 目录下执行
./gradlew :bz_web_app:bootJar

# 打包完成后，JAR 文件位于：
# bz_web_app/build/libs/bz_web_app-1.0-SNAPSHOT.jar
```

### 2.2 查看 JAR 包结构

```bash
# 查看 JAR 包中的内容（验证是否包含所有依赖）
jar tf bz_web_app/build/libs/bz_web_app-1.0-SNAPSHOT.jar | head -20
```

预期包含：
- `BOOT-INF/classes/`：项目编译后的 class 文件
- `BOOT-INF/lib/`：所有第三方依赖 JAR
- `org/springframework/boot/loader/`：Spring Boot 启动加载器

## 3. 启动部署

### 3.1 基本启动命令

```bash
# 启动应用（前台运行，Ctrl+C 停止）
java -jar bz_web_app/build/libs/bz_web_app-1.0-SNAPSHOT.jar

# 后台运行（推荐生产环境使用）
nohup java -jar bz_web_app/build/libs/bz_web_app-1.0-SNAPSHOT.jar > app.log 2>&1 &

# 查看启动日志
tail -f app.log
```

### 3.2 指定运行端口

```bash
# 指定端口启动（覆盖 application.yml 中的配置）
java -jar bz_web_app-1.0-SNAPSHOT.jar --server.port=9090
```

### 3.3 指定 JVM 参数

```bash
# 设置最大堆内存和最小堆内存
java -Xms512m -Xmx1024m -jar bz_web_app-1.0-SNAPSHOT.jar
```

**JVM 参数说明**：
| 参数 | 说明 | 推荐值 |
| :--- | :--- | :--- |
| `-Xms` | 初始堆内存 | 512m |
| `-Xmx` | 最大堆内存 | 1024m（根据服务器内存调整） |
| `-XX:+PrintGCDetails` | 打印 GC 详细日志 | 生产环境可关闭 |

## 4. 生产环境配置

### 4.1 创建生产环境配置文件

文件路径：`bz_web_app/src/main/resources/application-prod.yml`

```yaml
# 生产环境专用配置，覆盖 application.yml 中的默认值

server:
  port: 8080

spring:
  datasource:
    # 生产环境数据库（使用环境变量读取密码，避免明文泄露）
    url: jdbc:mysql://production-db-host:3306/barezen_oa?useSSL=true&serverTimezone=Asia/Shanghai&characterEncoding=utf8mb4
    username: prod_user
    password: ${DB_PASSWORD}      # 从环境变量读取密码
    driver-class-name: com.mysql.cj.jdbc.Driver

  redis:
    host: production-redis-host
    port: 6379
    password: ${REDIS_PASSWORD}   # 从环境变量读取密码

  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: Asia/Shanghai

logging:
  level:
    root: WARN                    # 生产环境减少日志输出
    com.linan: INFO
  file:
    name: logs/application.log    # 日志输出到文件而非控制台
```

启动时指定 profile：

```bash
# 设置环境变量并启动
export DB_PASSWORD=your_db_password
export REDIS_PASSWORD=your_redis_password
java -jar bz_web_app-1.0-SNAPSHOT.jar --spring.profiles.active=prod
```

## 5. 使用 Makefile 简化操作

在项目根目录的 `Makefile` 中添加打包和启动命令：

```makefile
# 打包
package:
	./gradlew :bz_web_app:bootJar

# 启动（开发环境）
run:
	./gradlew :bz_web_app:bootRun

# 启动（生产环境）
start:
	nohup java -jar bz_web_app/build/libs/bz_web_app-1.0-SNAPSHOT.jar > app.log 2>&1 &

# 停止
stop:
	@PID=$$(ps aux | grep bz_web_app | grep -v grep | awk '{print $$2}'); \
	if [ -n "$$PID" ]; then kill $$PID && echo "已停止进程 $$PID"; else echo "No running process found"; fi
```

使用方式：

```bash
make package    # 打包
make run        # 开发环境启动
make start      # 生产环境启动
make stop       # 停止应用
```

## 7. Docker 容器化部署

### 7.1 Dockerfile 说明

项目根目录提供了 `Dockerfile`，采用多阶段构建：

```dockerfile
# 第一阶段：构建
FROM eclipse-temurin:21-jre-alpine AS builder
WORKDIR /app
COPY build.gradle.kts settings.gradle.kts gradlew ./
COPY gradle gradle
COPY bz_framework_core bz_framework_core
COPY bz_web_app bz_web_app
RUN chmod +x gradlew && ./gradlew :bz_web_app:bootJar --no-daemon

# 第二阶段：运行
FROM eclipse-temurin:21-jre-alpine
WORKDIR /app
COPY --from=builder /app/bz_web_app/build/libs/*.jar app.jar
RUN apk add --no-cache curl
EXPOSE 8080
ENV TZ=Asia/Shanghai
ENTRYPOINT ["java", "-jar", "-Xms256m", "-Xmx512m", "/app/app.jar"]
```

### 7.2 构建 Docker 镜像

```bash
# 在 backend 目录下执行
docker build -t barezen-base:latest .

# 查看镜像
docker images | grep barezen
```

### 7.3 运行容器

```bash
# 运行（需要先启动 MySQL 和 Redis）
docker run -d \
  --name barezen-base \
  -p 8080:8080 \
  -e TZ=Asia/Shanghai \
  --link zen-mysql \
  --link zen-redis \
  barezen-base:latest
```

### 7.4 Docker Compose 完整部署

```yaml
version: '3.8'
services:
  mysql:
    image: mysql:8.0
    container_name: zen-mysql
    environment:
      MYSQL_ROOT_PASSWORD: 123456
      MYSQL_DATABASE: barezen_oa
    ports:
      - "3306:3306"
    volumes:
      - ./data/mysql:/var/lib/mysql
    command: --default-authentication-plugin=mysql_native_password --character-set-server=utf8mb4

  redis:
    image: redis:7.0
    container_name: zen-redis
    ports:
      - "6379:6379"
    volumes:
      - ./data/redis:/data

  app:
    build: .
    container_name: barezen-app
    ports:
      - "8080:8080"
    depends_on:
      - mysql
      - redis
    environment:
      - TZ=Asia/Shanghai
    # 注意：需要配置 application-prod.yml 使用容器网络名作为 host
```
