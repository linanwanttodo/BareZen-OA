# 17 - 前后端对接

> **前置要求**：后端全部完成，前端全部完成。

## 17.1 接口对接清单

### 17.1.1 认证模块对接

| 前端方法 | 后端接口 | 说明 |
|:---|:---|:---|
| `login()` | `POST /api/auth/v1/login` | 返回 Token + 用户信息 |
| `logout()` | `POST /api/auth/v1/logout` | 清除 Redis 在线状态 |
| `getCaptcha()` | `GET /api/auth/v1/captcha` | 返回 SVG Base64 + UUID |
| `getCurrentUser()` | `GET /api/auth/v1/current/user` | 获取当前用户信息 |

### 17.1.2 用户管理对接

| 前端方法 | 后端接口 | 说明 |
|:---|:---|:---|
| `getUserList()` | `GET /api/system/v1/users` | 分页查询 |
| `getUser()` | `GET /api/system/v1/users/{id}` | 单条查询 |
| `addUser()` | `POST /api/system/v1/users` | 新增 |
| `updateUser()` | `PUT /api/system/v1/users/{id}` | 修改 |
| `deleteUser()` | `DELETE /api/system/v1/users/{id}` | 删除 |
| `batchDeleteUsers()` | `DELETE /api/system/v1/users/batch` | 批量删除 |
| `changeUserStatus()` | `PUT /api/system/v1/users/{id}/status` | 状态切换 |

### 17.1.3 动态路由对接

```
前端登录成功 → buildDynamicRoutes() → getRouters()
                                           ↓
                              后端返回 MenuItem[] 树形结构
                                           ↓
                              generateRoutes() → AppRouteRecordRaw[]
                                           ↓
                              addRoutes() → Vue Router 注册
```

## 17.2 跨域处理

开发环境通过 Vite 代理解决：

```typescript
// vite.config.ts
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

生产环境通过 Nginx 反向代理：

```nginx
location /api/ {
  proxy_pass http://backend:8080;
}
```

## 17.3 常见对接问题

### Q1: 401 但 Token 未过期

检查请求拦截器是否正确注入 Authorization 头：

```typescript
if (token && config.headers) {
  config.headers['Authorization'] = `Bearer ${token}`
}
```

### Q2: 动态路由刷新 404

确保 Nginx 配置了 `try_files $uri $uri/ /index.html`

### Q3: 登录后路由空白

动态路由加载是异步的，需要 `next({ ...to, replace: true })` 确保路由已注册后再跳转。
