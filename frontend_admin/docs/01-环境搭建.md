# 01 - 环境搭建

> **前置要求**：无。零基础开始。

## 1.1 Node.js 安装（nvm 管理多版本）

Node.js 版本众多，建议使用 **nvm** 管理多版本，方便切换。

### Step 1：安装 nvm

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 重新加载 shell 配置
source ~/.zshrc   # macOS / zsh
# 或
source ~/.bashrc   # Linux / bash

# 验证安装
nvm --version
```

### Step 2：安装 Node.js 22.x

```bash
# 安装 LTS 版本
nvm install 22

# 设为默认版本
nvm alias default 22

# 验证
node --version   # v22.x.x
npm --version    # 10.x.x
```

### Step 3：设置 npm 镜像（可选）

```bash
# 切换为淘宝镜像（国内加速）
npm config set registry https://registry.npmmirror.com

# 恢复官方镜像
npm config set registry https://registry.npmjs.org
```

## 1.2 pnpm 安装

pnpm 是高性能的包管理器，比 npm/yarn 更快、更省空间。

```bash
# 通过 npm 安装（全局安装）
npm install -g pnpm

# 验证
pnpm --version   # 9.x.x
```

> 如果遇到权限问题（macOS/Linux）：
> ```bash
> sudo npm install -g pnpm
> ```

## 1.3 开发工具配置

### VS Code 扩展推荐

```bash
# 列出当前已安装的扩展
code --list-extensions
```

推荐安装以下扩展：

| 扩展名 | 功能 |
|:---|:---|
| `Vue.volar` | Vue 3 语言支持（推荐，比 Vetur 更先进） |
| `Vue.vscode-snippets` | Vue 代码片段 |
| `bradlc.vscode-tailwindcss` | Tailwind CSS 智能提示 |
| `editorconfig.editorconfig` | 统一编辑器配置 |
| `dbaeumer.vscode-eslint` | ESLint 支持 |
| `esbenp.prettier-vscode` | Prettier 代码格式化 |
| `formulahendry.code-runner` | 代码运行器 |
| `christian-kohler.path-intellisense` | 路径智能提示 |
| `ZixuanChen.vitest-explorer` | Vitest 测试（后续单元测试用到） |

### 一键安装推荐扩展

```bash
# 在 VS Code 中按 Cmd+Shift+P，输入 "Extensions: Install Extensions from VSIX"
# 或命令行安装
code --install-extension Vue.volar
code --install-extension bradlc.vscode-tailwindcss
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode
code --install-extension editorconfig.editorconfig
```

## 1.4 创建项目

### Step 1：创建项目目录

```bash
cd /home/lin/桌面/BareZen_Base

# 创建项目目录
mkdir -p frontend_admin
cd frontend_admin
```

### Step 2：初始化 Vite + Vue + TypeScript 项目

```bash
pnpm create vite@latest . -- --template vue-ts
```

> **注意**：在已有内容的目录下运行会提示确认。输入 `y` 继续。

输出应类似：
```
√ Project name: ... frontend_admin
√ Select a variant: vue-ts

Scaffolding project in /home/lin/桌面/BareZen_Base/frontend_admin...

Done. Now run:
  pnpm install
  pnpm dev
```

### Step 3：安装依赖

```bash
# 安装基础依赖
pnpm install

# 安装项目所需的核心依赖
pnpm add vue vue-router@4 pinia element-plus @element-plus/icons-vue axios
pnpm add -D @vueuse/core sass
```

### Step 4：安装 ESLint + Prettier

```bash
# 安装 ESLint 相关依赖
pnpm add -D eslint prettier eslint-plugin-vue @typescript-eslint/parser @typescript-eslint/eslint-plugin eslint-config-prettier
```

### Step 5：安装 Auto Import 插件（可选但推荐）

```bash
pnpm add -D unplugin-auto-import unplugin-vue-components
```

## 1.5 验证环境

```bash
# 进入项目目录
cd /home/lin/桌面/BareZen_Base/frontend_admin

# 启动开发服务器
pnpm dev
```

正常情况应输出：

在浏览器打开 `http://localhost:5173/`，看到 Vue 默认页面即为环境搭建成功。

## 1.6 常见问题

### Q1: pnpm install 报错 "EACCES"

```bash
# 修复权限
sudo chown -R $USER ~/.npm
sudo chown -R $USER ~/.pnpm-store
```

### Q2: node 版本不对

```bash
# 查看当前版本
node --version

# 切换到正确版本
nvm use 22

# 如果项目有 .nvmrc 文件，直接
nvm use
```

### Q3: 端口被占用

```bash
# 查看端口占用
lsof -i :5173

# 或者换一个端口启动
pnpm dev -- --port 5174
```
