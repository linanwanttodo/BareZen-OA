# 00 - 项目规范

## 1.1 项目背景

`frontend_admin` 是 BareZen_OA 全栈框架的**管理后台前端**，面向系统管理员使用。

管理后台通常需要：
- **丰富的交互**：表格、表单、弹窗、树形控件
- **复杂的权限控制**：菜单可见性、按钮级别权限
- **数据密集型展示**：分页、筛选、导出

因此选用 **Element Plus** 作为 UI 组件库，牺牲一定的包体积换取开发效率。

## 1.4 命名规范

| 类型 | 规范 | 示例 |
|:---|:---|:---|
| 目录 | kebab-case（全小写 + 连字符） | `user-manage`, `oper-log` |
| Vue 文件 | PascalCase（大写开头的驼峰） | `UserManage.vue`, `RoleList.vue` |
| TS/JS 文件 | kebab-case 或 camelCase | `use-page.ts`, `usePage.ts` |
| 变量/函数 | camelCase | `userName`, `getUserList` |
| 常量 | UPPER_SNAKE_CASE | `MAX_FILE_SIZE`, `DEFAULT_PAGE_SIZE` |
| 类型/接口 | PascalCase（I 开头或不加前缀） | `IUserInfo`, `UserInfo` |
| CSS 类名 | kebab-case | `.user-avatar`, `.el-button--primary` |
| SCSS 变量 | 以 `$bz-` 前缀开头 | `$bz-primary-color` |

## 1.5 代码风格

- **Vue 模板**：属性较多时每个属性占一行，闭合符号对齐
- **`<script setup>`**：始终使用 Composition API + `<script setup>` 语法
- **类型导入**：显式声明类型，避免 `any`
- **组件引用**：自动导入（unplugin-auto-import + unplugin-vue-components）
- **注释**：公共函数必须写 JSDoc 注释
