## 1.1 设计系统来源

本设计系统由 **UI/UX Pro Max** 技能自动生成，基于产品类型、风格关键词、配色方案、字体搭配等数据驱动决策。

```
设计系统文件：
  /home/lin/桌面/design-system/barezen/MASTER.md   ← 管理后台全局规范
  /home/lin/桌面/design-system/barezen/pages/      ← 页面级覆盖
  /home/lin/桌面/design-system/barezenuser/MASTER.md    ← 用户前台全局规范
  /home/lin/桌面/design-system/barezenuser/pages/       ← 页面级覆盖
```

**使用逻辑**：构建具体页面时，先检查 `pages/[页面名].md` 是否存在。如果存在，其规则**覆盖** MASTER.md；否则严格遵循 MASTER.md。

### 组件样式规范

#### 按钮 (Buttons)

```vue
<!-- 主要按钮：橙色 CTA -->
<el-button type="primary" class="bg-cta-500 text-white">
  新增
</el-button>

<!-- 次要按钮：透明底 + 紫色边框文字 -->
<el-button class="border-primary-600 text-primary-600">
  取消
</el-button>

<!-- 危险按钮 -->
<el-button type="danger" class="bg-red-500 text-white">
  删除
</el-button>
```

#### 卡片 (Cards)

```vue
<div class="bg-primary-50 rounded-lg p-6 border border-gray-200 cursor-pointer">
  <!-- 内容 -->
</div>
```

> **注意**：企业扁平风格不使用悬浮位移（`translateY`/`scale`）。状态变化仅通过边框或背景色表达，避免布局偏移。

#### 输入框 (Inputs)

```vue
<el-input
  class="focus:border-primary-600 focus:ring-4 focus:ring-primary-600/10"
  placeholder="请输入..."
/>
```

Element Plus 默认样式已较为美观，主要覆盖 focus 状态：

```scss
// element-plus.scss
.el-input {
  --el-input-focus-border-color: #{$primary};
  --el-input-focus-ring-color: #{$primary}20;
}
```

#### 表格 (Tables)

```vue
<!-- 表格行 -->
<el-table class="cursor-pointer">
```

#### 加载状态

```vue
<!-- 使用骨架屏，不允许 UI 冻结 -->
<el-skeleton :rows="5" animated />

<!-- 或使用 spinner -->
<el-icon class="is-loading animate-spin text-primary-600" />
```

### 深色模式说明

本设计系统**默认仅支持 Light Mode**。如需暗色模式，须确保：
- 背景使用 `#121212` 或 `#0D0D0D`
- 文字使用 `#FFFFFF` 或 `#E0E0E0`，对比度 ≥ 7:1
- 边框使用 `border-white/20`
- 不使用 `bg-white/10`（过于透明）

## 1.4 通用规范（两个前端共享）

### 必须遵守

| 规范 | 说明 |
|:---|:---|
| **无 Emoji 图标** | 必须使用 SVG 图标 (Lucide / Heroicons) |
| **cursor-pointer** | 所有可点击元素必须有 `cursor-pointer` |
| **平滑过渡** | 所有状态变化使用 `` (150-300ms) |
| **文字对比度** | Light Mode 正文 ≥ 4.5:1，辅助文字 ≥ 3:1 |
| **Focus 可见** | 键盘导航时 focus 状态必须可见 |
| **prefers-reduced-motion** | 尊重用户减少动画偏好 |
| **响应式测试** | 375px / 768px / 1024px / 1440px 断点验证 |

### 禁止模式

| 禁止 | 替代方案 |
|:---|:---|
| Emoji 作为 UI 图标 | SVG 图标 |
| 悬浮位移 / `scale` 动画 | 边框或背景色变化（仅颜色，无 transform） |
| 渐变背景 | 纯色背景 `bg-primary-600` |
| 透明度过高的背景 | `bg-white/80` 或更高不透明度 |
| 浅色正文文字 | 深色文字 `text-gray-900` |
| 无 Focus 状态 | `focus:ring-2 focus:ring-primary-500` |
| `#FFFFFF` 作为暗色背景 | `#121212` |

## 1.5 Pre-Delivery Checklist

每次交付代码前必须逐项检查：

```markdown
### 视觉质量
- [ ] 无 Emoji 作为图标（用 SVG）
- [ ] 所有图标来自统一图标集（Lucide）
- [ ] 无悬浮位移（translateY/scale）导致布局偏移
- [ ] 使用主题色（如 `bg-primary-600`）而非 `var()` 包装

### 交互
- [ ] 所有可点击元素有 `cursor-pointer`
- [ ] 状态变化通过边框/背景色清晰表达
- [ ] 过渡平滑（150-300ms）
- [ ] 键盘导航 focus 状态可见

### Light/Dark Mode
- [ ] Light Mode 文字对比度 ≥ 4.5:1
- [ ] 玻璃/透明元素在 Light Mode 可见
- [ ] 两个模式边框均可见

### 布局
- [ ] 浮动元素与边缘有适当间距
- [ ] 内容不被固定导航栏遮挡
- [ ] 响应式：375px / 768px / 1024px / 1440px
- [ ] 移动端无水平滚动

### 无障碍
- [ ] 所有图片有 alt 属性
- [ ] 表单输入有 label
- [ ] 颜色不是唯一指示器
- [ ] `prefers-reduced-motion` 被尊重
```
