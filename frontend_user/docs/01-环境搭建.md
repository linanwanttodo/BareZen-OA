# 01 - 环境搭建

> **前置要求**：无。

## 1.1 与管理后台共享环境

frontend_user 和 frontend_admin 共用同一套 Node.js + pnpm 环境，无需重复安装。

如果还未安装，参考 `frontend_admin/docs/01-环境搭建.md` 完成环境配置。

## 1.2 创建项目

```bash
cd /home/lin/桌面/BareZen_Base

# 创建用户前台目录
mkdir -p frontend_user
cd frontend_user

# 初始化 Vite + Vue + TypeScript 项目
pnpm create vite@latest . -- --template vue-ts

# 确认提示输入 y
```

## 1.3 安装依赖

```bash
# 基础依赖（Vue 相关）
pnpm install

# 核心依赖
pnpm add vue vue-router@4 pinia axios @iconify/vue @vueuse/core

# Tailwind CSS + 相关
pnpm add -D tailwindcss postcss autoprefixer
pnpm add -D @tailwindcss/forms @tailwindcss/typography

# 开发工具
pnpm add -D eslint prettier
```

## 1.4 Tailwind CSS 配置

### Step 1：初始化 Tailwind CSS

```bash
npx tailwindcss init -p
```

这会在项目根目录生成 `tailwind.config.js` 和 `postcss.config.js`。

### Step 2：配置 tailwind.config.js

```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    './index.html',
    './src/**/*.{vue,js,ts,jsx,tsx}'
  ],
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#eff6ff',
          100: '#dbeafe',
          200: '#bfdbfe',
          300: '#93c5fd',
          400: '#60a5fa',
          500: '#3b82f6',
          600: '#2563eb',
          700: '#1d4ed8',
          800: '#1e40af',
          900: '#1e3a8a'
        }
      },
      fontFamily: {
        sans: ['Inter', 'system-ui', '-apple-system', 'sans-serif']
      }
    }
  },
  plugins: []
}
```

### Step 3：配置主样式文件

创建 `src/assets/styles/main.css`：

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

/* 全局基础样式 */
@layer base {
  html {
    @apply antialiased;
  }

  body {
    @apply bg-gray-50 text-gray-900;
  }
}

/* 组件层：自定义组件类 */
@layer components {
  .btn {
    @apply px-4 py-2 rounded-lg font-medium duration-200;
  }

  .btn-primary {
    @apply btn bg-primary-600 text-white;
  }

  .btn-outline {
    @apply btn border border-gray-300 text-gray-700;
  }

  .card {
    @apply bg-white rounded-xl shadow-sm border border-gray-100 overflow-hidden;
  }

  .input {
    @apply w-full px-3 py-2 border border-gray-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-primary-500 focus:border-transparent;
  }
}
```

### Step 4：导入样式

在 `src/main.ts` 中导入：

```typescript
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import { createPinia } from 'pinia'
import './assets/styles/main.css'

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.mount('#app')
```

### Step 5：配置 PostCSS（PostCSS 插件顺序很重要）

确认 `postcss.config.js` 内容：

```javascript
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {}
  }
}
```

## 1.7 常见问题

### Q1: Tailwind CSS 类名不生效

检查 `tailwind.config.js` 中的 `content` 数组是否包含所有模板文件路径：

```javascript
content: [
  './index.html',
  './src/**/*.{vue,js,ts,jsx,tsx}'  // 确保通配符正确
]
```

### Q2: PostCSS 报错

确保 `postcss.config.js` 的插件顺序为：`tailwindcss` 在前，`autoprefixer` 在后。

### Q3: 暗色模式不生效

确保 `darkMode` 配置为 `'class'`，并在 HTML 根元素上添加 `dark` 类：

```html
<html class="dark">
  <!-- 暗色模式生效 -->
</html>
```
