## 1.2 技术栈

`frontend_user` 是 BareZen_OA 全栈框架的**用户前台**，面向普通终端用户使用。

用户前台通常需要：
- **美观简洁**：强调视觉体验和交互流畅度
- **响应式设计**：PC 和移动端自适应
- **内容驱动**：以内容展示为核心

因此选用 **Tailwind CSS** 作为样式方案，追求设计灵活性和包体积最小化。

## 1.6 Tailwind CSS 核心概念

Tailwind CSS 通过原子化类名实现样式，避免手写 CSS。

### 常用类名速查

```html
<!-- 文本 -->
<span class="text-sm text-gray-500">灰色小字</span>
<span class="text-xl font-bold text-blue-600">蓝色加粗大字</span>

<!-- 间距 (margin/padding) -->
<div class="m-4 p-4">4px 外边距 + 4px 内边距</div>
<div class="mx-auto px-6 py-3">水平居中 + 横向6 纵向3</div>

<!-- Flex 布局 -->
<div class="flex items-center justify-between">flex 居中 + 两端对齐</div>

<!-- 颜色 -->
<div class="bg-white text-gray-700 border border-gray-200 rounded-lg shadow-sm">
  白色背景 + 深灰文字 + 灰色边框 + 圆角 + 阴影
</div>

<!-- 响应式前缀 -->
<div class="hidden md:block lg:flex">移动端隐藏，桌面端显示</div>
<div class="w-full md:w-1/2 lg:w-1/3">移动端100%，平板50%，桌面33%</div>

<!-- 暗色模式 -->
<div class="bg-white dark:bg-gray-900 dark:text-white">支持暗色主题</div>
```
